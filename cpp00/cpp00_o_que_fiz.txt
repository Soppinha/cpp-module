EX00 — Megaphone
----------------------------------------------------------------
O que fiz:
    Programa que recebe argumentos da linha de comando e imprime
    tudo em maiúsculas usando std::toupper (de <cctype>).
    Se não receber argumentos, imprime uma mensagem padrão.

Por que fiz assim:
    toupper opera em char, então iterei caractere a caractere
    com dois loops aninhados — um para cada argumento, outro
    para cada caractere. É a forma mais direta sem usar strings
    de C++. Usar av[i][j] diretamente (char*) é suficiente aqui
    porque o exercício não exige manipulação complexa de strings.

EX01 — Phonebook
----------------------------------------------------------------
O que fiz:
    Dois arquivos de classe: Contact (guarda os dados de um
    contato) e PhoneBook (gerencia até 8 contatos com lógica
    de slot circular).

    - Contact tem atributos private e getters/setters públicos.
    - PhoneBook tem um array estático de 8 Contacts e um
      contador de quantos foram adicionados.
    - addContact() usa um helper readField() para rejeitar
      campos vazios em loop.
    - searchContact() exibe a tabela com std::setw(10) para
      alinhar colunas e trunca strings longas (>10 chars) com
      função auxiliar truncate().
    - O slot de inserção é count % 8, então ao passar de 8
      contatos sobrescreve o mais antigo.

Por que fiz assim:
    A separação em duas classes (Contact / PhoneBook) respeita
    responsabilidade única — Contact não sabe nada sobre o
    livro, e PhoneBook não sabe sobre os detalhes de cada campo.
    readField() em loop evita código duplicado para os 5 campos.
    A lógica count % 8 é o modo mais simples de implementar
    o comportamento circular exigido pelo enunciado sem precisar
    de estrutura de dados dinâmica.

    Após ler com std::cin >> index precisei chamar
    std::cin.ignore() para consumir o '\n' residual antes de
    futuros std::getline — caso contrário a próxima leitura
    capturaria uma linha vazia.
